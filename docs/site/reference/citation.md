## Cite a reproducible version

Cite the repository together with the exact revision or release you used. Include a software publication or archived release DOI when one is available.

```bibtex
@software{a11yresearch,
  author = {Vera-Amaro, Guillermo and Rojano-Cáceres, José Rafael},
  title = {A11yResearch: Web Accessibility Research Platform},
  url = {https://github.com/gverafei/web-accessibility-research-platform},
  note = {Specify the release or commit used in the experiment}
}
```

For an experiment, also preserve the pinned ranking/corpus, source and configuration digests, actual tool versions and relevant model/reasoning selection. The software citation is not a replacement for the dataset's own provenance.

## Reporting research

The acquisition, remediation and comparison records provide source provenance, configured controls, measured results and resource usage for a methods section. Capture dates and reuse links distinguish fresh acquisitions from imported or previously stored evidence.
